# Аудитория

Две стороны маркетплейса исследуются раздельно:

- **SUPPLY** — те, кто предоставляет технику (частные владельцы, владельцы нескольких машин, автопарки, прокаты, владельцы спецтехники — список сегментов уточняется интервью и исследованием).
- **DEMAND** — те, кто арендует (частные лица, компании — уточняется).

Предположения основателя о ЦА не принимаются автоматически — каждый сегмент подтверждается внешними данными (поисковый спрос, отзывы, форумы, соцсети, данные продукта).

## Планируемые файлы

- `segments.md` — карта сегментов supply и demand с размером, доступностью, приоритетом (P0–P3).
- `profile-<side>-<segment>.md` — customer profile на каждый приоритетный сегмент.
