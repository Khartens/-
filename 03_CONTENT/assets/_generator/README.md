# Генератор графики Машина.РФ

Скрипты, которые рисуют всю графику в `03_CONTENT/assets/`: обложки рилсов, сторис, посты, карточки, аватары, баннеры и логотип. Нужны, чтобы быстро пересобрать картинки, если поменяется текст, логотип или стиль.

## Как запустить

```bash
pip install pillow numpy
python3 03_CONTENT/assets/_generator/build_covers.py          # все 82 обложки
python3 03_CONTENT/assets/_generator/build_covers.py S13 S14  # только выбранные
python3 03_CONTENT/assets/_generator/build_rest.py            # логотип, аватары, баннеры, сторис, посты, карточки
```

## Что где менять

| Файл | Что внутри |
|---|---|
| `covers_data.py` | Тексты обложек: серия + 2 строки для каждого сценария S01–S82 |
| `build_rest.py` | Тексты сторис, постов, карточек и баннеров |
| `render.py` | Стиль: цвета сайта, отступы, правило «ровно 2 строки», размеры шрифта |
| `logo.py` | Логотип: «М»-лента и надпись «Машина.РФ» |
| `fonts/` | Шрифты Inter и Montserrat |

## Правила

- Текст на картинке — ровно 2 строки, каждая целиком в одну строку (см. `03_CONTENT/assets/README.md`).
- Города не называем (D-16).
- Логотип нарисован по образцу основателя. Когда будет финальный файл от дизайнера, заменить `logo.py` на вставку этого файла и пересобрать.
