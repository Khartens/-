# 00_FOUNDATION — фундамент

То, на что опирается вся система. Если здесь чего-то нет — в стратегии это не может считаться фактом.

| Файл | Что внутри |
|---|---|
| [`project-brief.md`](project-brief.md) | Что мы знаем о продукте, бизнесе, рынке. Каждое утверждение: FACT / FOUNDER INPUT / HYPOTHESIS / UNKNOWN |
| [`founder-interview.md`](founder-interview.md) | Все раунды discovery-интервью: вопросы, ответы основателя, выводы, противоречия |
| [`sources.md`](sources.md) | Реестр источников: что проверяли, когда, что нашли, что было недоступно |

Позже здесь появятся (только когда будет содержание):
- `decision-log.md` — принятые основателем решения (позиционирование, города, категории, бюджет) с датой.
- `glossary.md` — термины маркетплейса (листинг, заявка, отклик, ликвидность и т.д.), если возникнет путаница.
