# 11_PARTNERSHIPS — партнёрства

Партнёры, которые могут приводить supply или demand: сервисы и СТО, страховые, лизинг, туризм и гостиницы, event-агентства, строительные компании (для спецтехники) и т.п. Список подтверждается research.

Планируется: `partner-map.md` (типы партнёров, ценность для обеих сторон, приоритет) и `partner-pipeline.md` (стадии переговоров, без персональных данных).
