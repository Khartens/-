# Метрики Машины.РФ — определения

**Дата:** 2026-10-02 · **Статус:** v1. Как собирать данные: [`analytics-recommendations.md`](analytics-recommendations.md).

## 1. North Star Metric (на выбор основателя 🟡)

| Вариант | Определение | Плюсы | Минусы |
|---|---|---|---|
| **A. Заявки с откликом за 2 часа в неделю** | Число опубликованных заявок, получивших ≥1 отклик за 2 часа | Сразу отражает ликвидность; считается из базы без участия пользователей | Не учитывает сделки через каталог |
| **B. Подтверждённые сделки в неделю** | Число сделок, подтверждённых хотя бы одной стороной (`deal-check` / опрос) | Ближе всего к ценности | Деньги не идут через платформу, поэтому подтверждения неполные |
| **C. Активные владельцы с ≥1 контактом за неделю** | Владельцы, получившие отклик, сообщение или показ телефона | Отражает ценность для платящей стороны | Не отражает успех арендатора |

**Рекомендация (HYPOTHESIS):** на этапе cold start — **A** (ведущая метрика), **B** — главная отстающая метрика в еженедельном обзоре.

## 2. Воронки

### Demand (арендатор)
`Визит → Начал заявку → Отправил заявку → Регистрация/код → Заявка опубликована (модерация) → ≥1 отклик → Ответ арендатора в чате → Сделка подтверждена → Отзыв`
Параллельная ветка: `Визит → Просмотр карточки → Показ телефона / Начат чат → Сделка`

### Supply (владелец)
`Визит → Начал объявление → Регистрация → Отправил объявление → Опубликовано → Telegram подключён → Первый контакт (отклик / чат / телефон) → Сделка → Платный тариф`

## 3. Определения

| Метрика | Формула | Источник |
|---|---|---|
| **Activation (владелец)** | Доля зарегистрированных владельцев с опубликованным объявлением за 7 дней | БД |
| **Activation (арендатор)** | Доля зарегистрированных арендаторов с опубликованной заявкой или начатым чатом за 1 день | БД |
| **Conversion (visit → request)** | Отправленные заявки / уникальные посетители | Метрика |
| **Conversion (visit → listing)** | Отправленные объявления / посетители страниц для владельцев | Метрика |
| **CAC (владелец)** | (Затраты на привлечение владельцев + оценка часов ручной работы × ставка) / новые активированные владельцы | Финансы + БД + UTM |
| **CAC (арендатор)** | Затраты на demand-каналы / новые арендаторы с опубликованной заявкой | Финансы + БД + UTM |
| **LTV (владелец)** | Средняя выручка с владельца за срок жизни = ARPU × средний срок подписки (мес.) + поднятия | Платежи |
| **ARPPU** | Выручка / платящие владельцы за месяц | Платежи |
| **Retention (владелец)** | Доля владельцев, активных (контакт или отклик) в месяц N после активации | БД |
| **Retention (арендатор)** | Доля арендаторов с повторной заявкой за 30 / 90 дней | БД |
| **Paid conversion** | Платящие владельцы / активные владельцы | Платежи + БД |

## 4. Метрики маркетплейса

| Группа | Метрика | Формула |
|---|---|---|
| **Supply** | Активные объявления | Число со статусом `active` (по категории × городу) |
| | Активные владельцы | Владельцы с активным объявлением и активностью за 14 дней |
| | Покрытие | Число подкатегорий × городов с ≥5 активными владельцами |
| **Demand** | Новые заявки | Опубликованные за период (категория × город) |
| | Просмотры каталога | Метрика |
| **Liquidity** | **Request fill rate** | Заявки с ≥1 откликом за 2 ч / опубликованные заявки |
| | Time to first response | Медиана (время первого отклика − время публикации) |
| | Responses per request | Отклики / заявки |
| | Listing contact rate | Объявления с ≥1 контактом за 14 дней / активные объявления |
| | Supply utilization (proxy) | Доля владельцев с ≥1 сделкой за месяц |
| **Transactions** | Подтверждённые сделки | Количество (категория × город) |
| | Request → deal | Сделки из заявок / заявки |
| | Средний чек сделки | Сумма из подтверждения (опционально) |
| | GMV (оценка) | Сумма чеков подтверждённых сделок. Только оценка: деньги не идут через платформу |
| **Trust** | Жалобы на 100 сделок | Жалобы / сделки × 100 |
| | Средний рейтинг | По отзывам |
| | Доля чатов с антифрод-предупреждением | Чаты с `safety`-флагом / все чаты |
| **Revenue** | MRR | Сумма активных подписок |
| | Выручка с поднятий | Сумма |
