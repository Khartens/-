# 04_INFLUENCERS — блогеры

Этап 12.

| Файл (планируется) | Что |
|---|---|
| `segmentation.md` | Сегменты блогеров (авто, путешествия, города, бизнес, спецтехника…), критерии поиска |
| `scoring.md` | Модель скоринга (релевантность аудитории, ER, гео, цена, риски) |
| `outreach-templates.md` | Тексты первого контакта и follow-up; модели: бартер / фикс / CPA / гибрид |
| `campaign-tracker.md` | Трекинг кампаний: UTM/промокоды, охват, клики, регистрации, листинги/заявки, сделки |

Юридические требования РФ к рекламе у блогеров (маркировка, ERID, регистрация в ОРД) учитываются в каждом шаблоне.
