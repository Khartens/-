## Фаза 1 — посадочные «категория × город» (P1, 2–4 недели после выбора города и ниши)

**Проблема:** категории и города сейчас передаются query-параметрами (`/ads-car?category=cars`). Отдельных индексируемых страниц под «аренда экскаватора Новосибирск» нет.

**Предложение (требует согласования архитектуры):**

| Тип страницы | URL-паттерн (пример) | Содержимое |
|---|---|---|
| Категория × город | `/arenda/ekskavatory/novosibirsk` | H1 «Аренда экскаватора в Новосибирске», объявления города, блок «Оставьте заявку», реальные цены (мин / медиана / макс из объявлений), FAQ, отзывы |
| Подкатегория × город | `/arenda/mini-ekskavatory/novosibirsk` | То же для подкатегории |
| Категория (вся РФ) | `/arenda/ekskavatory` | Список городов с объявлениями |
| Заявки категории × город | `/zayavki/ekskavatory/novosibirsk` | Для владельцев: «Кто ищет экскаватор в Новосибирске» |

**Правила, чтобы не наплодить мусор:**
- Индексировать страницу «категория × город» только при ≥3 активных объявлениях (иначе `noindex`).
- Уникальный текстовый блок с реальными цифрами города (цены, число владельцев).
- Микроразметка `Product` / `Offer` / `AggregateRating` (при наличии отзывов), `BreadcrumbList`, `FAQPage`.

**Первые 10–20 посадочных:** выбираются по частотности Wordstat (P0-кластеры ниши запуска × город запуска).

## Фаза 2 — карточки и контент (P1–P2, 1–2 месяца)

| # | Задача |
|---|---|
| SEO-2.1 | ЧПУ для карточек: `/arenda/<category>/<city>/<slug>` вместо `/car-ad?slug=` (с 301 со старых URL) |
| SEO-2.2 | Шаблон meta description карточки: «[Техника] в аренду в [город] — [цена]/[период]. [С оператором/без]. Напрямую от владельца» вместо текста пользователя |
| SEO-2.3 | Блог или раздел статей на сайте (или Дзен с ссылками) по информационным кластерам: 2 статьи в неделю, начиная с «сколько стоит» |
| SEO-2.4 | Перелинковка: карточка → категория × город → соседние категории → статьи |
| SEO-2.5 | Страница «Владельцам техники» под supply-запросы («сдать спецтехнику в аренду») |
