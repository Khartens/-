# Keyword Clusters — Машина.РФ

**Дата:** 2026-10-02 · **Статус:** v1, структура кластеров. **Частотность — UNKNOWN**: нужна выгрузка из Яндекс Wordstat (см. [`../01_RESEARCH/demand-and-seasonality.md`](../01_RESEARCH/demand-and-seasonality.md)).
Основной поисковик рынка — **Яндекс**.

## 1. Формула транзакционного запроса

`[действие] + [техника/категория] + [модификатор] + [город]`

| Элемент | Варианты |
|---|---|
| Действие | аренда, прокат, заказать, снять, взять в аренду, услуги, нанять |
| Техника | см. §2 (по слагам категорий сайта) |
| Модификатор | цена, недорого, посуточно, почасово, на час, на сутки, с водителем / с оператором, без водителя, без залога, под такси, на месяц, от владельца, частник |
| Город | город запуска + области и районы + пригороды |
