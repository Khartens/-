**Текущее позиционирование на сайте (FACT):** «Аренда транспорта напрямую у владельцев… Напрямую и без комиссии». Оно описывает модель («напрямую, без комиссии»), но не выгоду и не отличие: те же слова у Перевозки 24, Specavto и других досок.

Proof: что уже есть в продукте и подтверждено аудитом (✅) или чего пока нет (⏳).

## Вариант 1. «Заявка вместо обзвона»
*Фокус: механика обратного аукциона как главная выгода для арендатора.*

| | |
|---|---|
| **Audience** | D1 (частник с разовой задачей), D2 (прораб); для supply — S1 |
| **Problem** | Чтобы найти технику, приходится обзванивать 10 объявлений, сравнивать цены и ждать ответов |
| **Promise** | Опишите задачу один раз, и владельцы сами предложат технику и цену |
| **Differentiation** | Для частника это редкость: на Авито нужно звонить самому. Каталог + заявки в одном месте для всех видов транспорта |
| **Proof** | ✅ заявки и отклики, ✅ чат, ✅ модерация; ⏳ «среднее время до первого отклика — N минут» (после запуска) |
| **Slogan** | «Напишите, что нужно, — владельцы предложат сами» |
| **Message** | «Нужен манипулятор, экскаватор или Газель? Не обзванивайте объявления. Оставьте заявку за 2 минуты — владельцы техники в [город] пришлют предложения с ценой. Бесплатно» |
| **CTA** | «Оставить заявку» |

## Вариант 2. «Без диспетчера»
*Фокус: supply-сторона спецтехники, экономия на посредниках.*

| | |
|---|---|
| **Audience** | S1, S2 (владельцы спецтехники и грузовиков) |
| **Problem** | Диспетчеры забирают 10–20% со смены, на Авито демпинг и нецелевые звонки |
| **Promise** | Заказы напрямую от заказчиков, без процента со смены, за фиксированные 0–990 ₽ в месяц |
| **Differentiation** | Дешевле профильных досок по мультиобъявлениям («Плюс» 299 ₽ на 10 объявлений); заявки приходят в Telegram |
| **Proof** | ✅ тарифы, ✅ Telegram-уведомления, ✅ отклики на заявки; ⏳ «N заявок на технику в [город] за неделю» |
| **Slogan** | «Заказы на технику — без диспетчера» |
| **Message** | «Диспетчер берёт 15% с каждой смены. Мы — 0%. Размещайте технику бесплатно и получайте заявки заказчиков из [город] прямо в Telegram» |
| **CTA** | «Разместить технику бесплатно» |

## Вариант 3. «Безопасная аренда напрямую»
*Фокус: доверие как отличие на рынке, где главная боль — мошенничество с предоплатой.*

| | |
|---|---|
| **Audience** | D1, D3, D5 (непрофессиональные арендаторы) + S1, S3 |
| **Problem** | Предоплата на карту пропадает, техника не приезжает, отзывы накручены |
| **Promise** | Договаривайтесь напрямую, но с защитой: проверенные объявления, честные отзывы, предупреждения о мошенниках |
| **Differentiation** | Отзывы только после реального взаимодействия; антифрод в чате (никто из конкурентов это не заявляет) |
| **Proof** | ✅ модерация, ✅ отзывы после взаимодействия, ✅ антифрод-предупреждения, ✅ жалобы; ⏳ проверка документов владельца (сейчас нет) |
| **Slogan** | «Напрямую — но не вслепую» |
| **Message** | «Аренда напрямую у владельцев без комиссии. Мы проверяем объявления, показываем только настоящие отзывы и предупреждаем, если в чате просят предоплату на карту» |
| **CTA** | «Найти проверенного владельца» |

⚠️ Риск: обещание безопасности без проверки документов и без гарантии сделки можно счесть преувеличением. Нужна аккуратная формулировка (без слов «гарантируем», «100% безопасно»).

## Вариант 4. «Всё, что ездит и летает»
*Фокус: широта каталога и эмоция; бренд для контента.*

| | |
|---|---|
| **Audience** | D3, D5; широкая аудитория соцсетей |
| **Problem** | Чтобы арендовать что-то необычное (снегоход, автодом, вертолёт), нужно искать по разным сайтам |
| **Promise** | От Газели до вертолёта — у владельцев рядом, в одном сервисе |
| **Differentiation** | Единственная площадка с 4 группами транспорта (у конкурентов — одна ниша) |
| **Proof** | ✅ 28 подкатегорий; ⏳ реальные объявления в каждой |
| **Slogan** | «Арендуй что угодно с мотором» |
| **Message** | «Квадроцикл на выходные, автодом в отпуск, экскаватор на дачу, вертолёт на праздник — всё у владельцев напрямую» |
| **CTA** | «Посмотреть, что можно арендовать» |

⚠️ Риск: при пустом каталоге обещание «всё» разочаровывает. Подходит для бренд-контента, но не как основное позиционирование на старте.

## Вариант 5. «Техника работает — вы зарабатываете»
*Фокус: доход владельца от простаивающей техники (supply-side, P2P и малый бизнес).*

| | |
|---|---|
| **Audience** | S1, S3, S5 |
| **Problem** | Техника или машина простаивает, а лизинг, налог и страховка списываются |
| **Promise** | Сдавайте технику в простои и закрывайте её расходы |
| **Differentiation** | Бесплатное размещение, заявки клиентов, календарь занятости, цена «с оператором / без» |
| **Proof** | ✅ календарь, ✅ варианты цены, ✅ бесплатный тариф; ⏳ кейсы владельцев с доходом |
| **Slogan** | «Простой — в доход» |
| **Message** | «Ваш манипулятор стоит без дела 10 дней в месяц? Разместите его бесплатно — заказчики из [город] сами пришлют заявки на свободные даты» |
| **CTA** | «Узнать, сколько можно заработать» |

## Вариант 6. «Местный сервис аренды техники [город]»
*Фокус: локальность, «свой» сервис в регионе.* **Не используется (D-16):** мы работаем по всей России и города не выделяем.

| | |
|---|---|
| **Audience** | Все сегменты одного города |
| **Problem** | Федеральные площадки — это шум и чужие города; местные владельцы теряются |
| **Promise** | Все местные владельцы техники и все заявки города — в одном месте; основатель на связи лично |
| **Differentiation** | Личное присутствие команды в городе, консьерж-подбор, местные сообщества |
| **Proof** | ⏳ «N владельцев из [город]», лицо основателя, локальные кейсы |
| **Slogan** | «Аренда техники в [город] — от своих» |
| **Message** | «Мы из [город] и знаем местных владельцев техники. Напишите, что нужно, — подберём за 30 минут» |
| **CTA** | «Написать нам в Telegram» |

| 5. Простой — в доход | ★★★★ (supply) | ★★★ | ★★ | Низкий |

**Наблюдение (не выбор):** позиционирование маркетплейса обычно двустороннее: одно сообщение для арендатора и одно для владельца. Часто сочетают **1 (demand) + 2 (supply)**, а **3** используют как слой доверия на всех страницах. Решение остаётся за основателем.
