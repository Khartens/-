# 10_EXPERIMENTS — эксперименты

Этап 17. Центр growth loop: каждая идея становится гипотезой с критериями успеха и провала.

| Файл | Что |
|---|---|
| [`backlog.md`](backlog.md) ✅ | 100 экспериментов с ICE-оценкой, объяснением оценок и приоритетом P0–P3 |
| `EXP-<id>.md` | Карточка запущенного эксперимента с результатом |
| `learnings.md` | Что мы узнали — короткие выводы по завершённым экспериментам |

## Поля эксперимента

`ID · Hypothesis · Audience · Channel · Action · Cost · Effort · Expected impact · Metric · Success criteria · Failure criteria · Status`

Статусы: `idea` → `ready` → `running` → `won` / `lost` / `inconclusive` → `archived`.

## Шкала ICE (1–10)
- **Impact** — насколько сдвинет ключевую метрику (сделки / ликвидность)
- **Confidence** — сколько подтверждающих данных (FACT > FOUNDER INPUT > HYPOTHESIS)
- **Ease** — стоимость и время (10 = бесплатно и за день)

Каждая оценка сопровождается одной строкой объяснения.
