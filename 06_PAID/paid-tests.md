# Карточки платных тестов

> ⏸ **На паузе (2026-10-02):** денежного бюджета на маркетинг нет — решение основателя D-07 ([`../00_FOUNDATION/decision-log.md`](../00_FOUNDATION/decision-log.md)). Документ остаётся как готовый план на момент, когда появится бюджет или первая выручка от подписок.


**Дата:** 2026-10-02 · Все тесты — **HYPOTHESIS**, статус `ready` после выполнения предусловий:
1) ≥30 владельцев в нише и городе; 2) Метрика + цели работают; 3) выбрано позиционирование.
`[город]` и `[ниша]` — из решения основателя. Бюджеты минимальные, для получения сигнала, а не для масштаба.

Шаблон: **Audience · Offer · Creative · Landing · Budget · KPI · Stop condition · Scale condition · Learning**.

## PT-01. Директ, поиск — горячий спрос арендаторов на технику (P0)
| | |
|---|---|
| **Audience** | Поиск в [город]: «аренда мини экскаватора», «заказать манипулятор», «газель с грузчиками», «экскаватор погрузчик аренда цена» + [город] |
| **Offer** | «Опишите задачу — владельцы техники в [город] сами предложат цену. Бесплатно» |
| **Creative** | 3 варианта объявлений: (A) «Заявка вместо обзвона», (B) «Цены от владельцев без посредников», (C) «Без предоплаты незнакомцам — проверенные объявления» (формулировку согласовать с позиционированием) |
| **Landing** | `/create-order` с предвыбранной категорией (если поддерживается) или `/ads-car?category=…` + блок «Оставить заявку» |
| **Budget** | 15 000 ₽ / 14 дней |
| **KPI** | CPL (заявка) ≤ 500 ₽; ≥70% заявок с ≥1 откликом за 2 часа |
| **Stop condition** | После 300 кликов CR в заявку < 2% **или** CPL > 1 000 ₽ |
| **Scale condition** | CPL ≤ 350 ₽ и fill rate ≥70% → бюджет ×2, расширение семантики |
| **Learning** | _заполняется после теста_ |

## PT-05. Посевы в городских Telegram-каналах (P1)
| | |
|---|---|
| **Audience** | 3–5 каналов [город] со скорингом ≥55 (см. `04_INFLUENCERS/influencer-playbook.md`) |
| **Offer** | Полезный пост: «Реальные цены на аренду техники в [город]» + «оставьте заявку» |

| **Scale condition** | Канал дал CPL ≤ 400 ₽ → повтор через 3–4 недели |
| **Learning** | — |
