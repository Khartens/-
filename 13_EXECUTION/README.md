| Файл (планируется) | Что |

**DATA → ANALYSIS → LEARNING → HYPOTHESIS → EXPERIMENT → RESULT → NEXT EXPERIMENT**

Файлы появятся, когда будет утверждено направление (после интервью и research). До этого текущие задачи фиксируются в `00_FOUNDATION/founder-interview.md` (раздел «Что нужно от основателя»).
