# Roadmap — 7 / 30 / 90 дней и 12 месяцев

**Версия:** 0.1 · **Дата:** 2026-10-02 · **Статус:** черновик. Пересматривается после интервью и выбора города и ниши, затем ежемесячно.
Основа: [`../02_STRATEGY/marketplace-strategy.md`](../02_STRATEGY/marketplace-strategy.md).

## 7 дней (до 2026-10-09) — этап 0

| Результат | Приоритет |
|---|---|
| Интервью, раунд 1 — ответы получены; раунд 2 задан | P0 |
| Решения: город, ниша, позиционирование (или дата решения) | P0 |
| Репозиторий приватный | P0 |
| Метрика: счётчик создан, ID у разработки; Вебмастер подключён | P0 |
| E-mail на «Контактах» исправлены | P0 |
| Wordstat-выгрузка по нише и городу | P1 |

## 30 дней (до 2026-11-01) — этапы 0 → 1

| Результат | Метрика |
|---|---|
| Тестовые данные удалены, аналитика и цели работают | Да |
| **30 активных владельцев** в нише и городе | 30 |
| Ручной цикл ликвидности работает | 100% заявок разосланы владельцам |
| Founder-сериал: 20+ выпусков | 20 |
| Первые 10–20 заявок через консьерж и посты | 10–20 |
| Принято решение по PR-1 (автоуведомления владельцам) | Да / нет + срок |

## 90 дней (до 2026-12-31) — этапы 1 → 3

| Результат | Метрика |
|---|---|
| **100 владельцев** в нише и городе (+ зимний модуль) | 100 |
| **100 заявок** | 100 |
| Fill rate за 2 ч | ≥70% |
| **50 подтверждённых сделок** | 50 |
| 20+ отзывов | 20 |
| Первые платные тесты (Директ, посевы) с CPL в пределах ориентира | CPL ≤ 500 ₽ |
| Посадочные «категория × город» (если согласовано) — первые 10 | 10 |

## 12 месяцев (до 2027-10) — этапы 4 → 5

| Квартал | Фокус | Ключевые результаты (HYPOTHESIS) |
|---|---|---|
| **Q4 2026** | Холодный старт в 1 городе и нише + зимний модуль | 100 владельцев, 50 сделок |
| **Q1 2027** | Локальная ликвидность; подготовка к сезону земляных работ; первые платящие владельцы | ≥50% заявок без ручной работы; request → deal ≥60%; MRR > 0 |
| **Q2 2027** | Сезон: масштаб demand в городе 1 (Директ, VK, SEO); соседние категории | Заявок ×3 к Q1; 10+ посадочных в топ-10 Яндекса |
| **Q3 2027** | Второй город по плейбуку (если метрики города 1 выполнены) | Город 2: 50 владельцев за 60 дней |
| **Q4 2027** | Повторение плейбука; оценка перехода на ИП/ООО и B2B-продуктов (документы, НДС) | 2–3 города с ликвидностью |

**Условия перехода между этапами** — строго по критериям выхода из `marketplace-strategy.md` §4, а не по календарю.
