# 05_OUTBOUND — прямое привлечение

Этап 11. Отдельный подход для каждого сегмента: владельцы авто, владельцы нескольких авто, автопарки, прокаты, спецтехника, компании (B2B). Итоговый список сегментов подтверждается research.

| Файл (планируется) | Что |
|---|---|
| `icp.md` | ICP по каждому сегменту + квалификация |
| `scripts-<segment>.md` | Скрипты, персонализация, follow-ups |
| `crm-fields.md` | Поля CRM, стадии, KPI воронки outbound |

Принципы: никакого спама; соблюдаем правила каждой площадки (Авито, Telegram, VK и т.д.), закон о рекламе и 152-ФЗ о персональных данных. Реальные контакты людей в репозиторий не попадают.
